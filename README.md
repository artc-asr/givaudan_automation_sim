# givaudan_automation_sim

Shelf-aisle simulation (two shelves, 494 trays, 16 796 vials) with rochestra robots
spawned between the shelves.

| Package | What |
|---|---|
| `src/shelf_world` | the world (generated by `scripts/generate_world.py`) |
| `src/givaudan_bringup` | `robot_in_aisle.launch.py`: one rochestra robot in the aisle, facing a shelf |
| `reachability/` | highest shelf level per robot and task, and the demo motion plans, with cuRobo (no ROS) |
| `tools/web_replay/` + `docs/` | the replay page: https://artc-asr.github.io/givaudan_automation_sim/ |
| `src/external/` | rochestra and its source deps, imported from `repos/main.repos` (not committed) |
| `deps/harmonic` | gz_ros2_control built for Gazebo Harmonic, from `repos/harmonic.repos` (not committed) |

## Setup (Ubuntu 22.04, ROS 2 Humble, Gazebo Harmonic)

```bash
./scripts/setup_workspace.sh          # vcs import (pinned) + build, ~4 min
```

## Run

```bash
source scripts/env.sh
ros2 launch givaudan_bringup robot_in_aisle.launch.py robot:=rby1 face:=A   # rby1 = Model M (mecanum)
ros2 launch givaudan_bringup robot_in_aisle.launch.py robot:=vb2  face:=B
ros2 launch givaudan_bringup robot_in_aisle.launch.py robot:=g1   face:=B gui:=false
ros2 launch givaudan_bringup robot_in_aisle.launch.py robot:=moz1 face:=B   # moz1: face B only (rochestra has no pose args yet)
```

`face:=B` = yaw 0 (towards shelf B, x > 0), `face:=A` = yaw pi. `x:=`/`y:=`/`yaw:=` move the robot (default aisle centre).
Each robot gets the physics step of its own rochestra world (see `PHYSICS` in the launch file).
After a pin change in `repos/main.repos`, update an existing checkout with
`vcs import --force src/external < repos/main.repos` (setup_workspace.sh skips existing ones).

Check a spawn headless (pose from Gazebo, RTF, controllers): `scripts/check_spawn.sh rby1 A`.

## Demo recording (the replay page)

```bash
# 1. plan (cuRobo venv, no ROS): the highest level whose whole motion plans, base pose included
env -u PYTHONPATH deps/curobo-venv/bin/python reachability/plan_demo.py --task 1
# 2. run it in Gazebo and record
source scripts/env.sh
ros2 launch givaudan_bringup demo.launch.py plan:=reachability/plans/task1_L08.json record:=/tmp/run_task1 gui:=false
# 3. build the page data
env -u PYTHONPATH deps/curobo-venv/bin/python tools/web_replay/build.py /tmp/run_task1
```

Grasps and suction are emulated with sim-only welds (Gazebo DetachableJoint on the demo
tray and vial, `generate_world.py --grip / --pick-vial`); the motions are the robot's own
trajectory controllers following the cuRobo plan.

Results (2026-10-16, rby1 Model M, rochestra D20 collision): **level 7 (board top 1.34 m) is the
highest level that plans end to end and runs in Gazebo for both tasks**: task 1 (pull 25 cm, suction-pick
a vial, lift 11.4 cm), task 2 (pull 55 cm one-handed while the back end rests on the board, support from
below, take it out together to 70 cm, lift 5 cm level). Hands within 0-6 mm of the plan at every grasp.
Limits found on the way: the stock gripper (126 mm) does not fit the 100 mm board gap, so the handle is
pinched with the fingertips, with < 2 mm to spare; one hand cannot hold the full tray once it leaves the
board (it dropped 17 cm and tilted 20 deg), hence the support from below before that.

## Known issues

- moz1 runs at ~0.03x real time in the aisle: at its spawn pose (no pose arguments in its
  rochestra launch) its grippers reach 4 cm into shelf B. Needs x/y/yaw arguments upstream.
- Real-time factor in the aisle (headless, sensors on): vb2 0.79, g1 0.80, rby1 0.96.
